# El desafío del error ortográfico
<!-- endhide -->

Aprender en público significa colaboración y no tienes que ser un experto para colaborar. ¡Los errores ortográficos vienen al rescate! El perfecto rompehielos para las contribuciones de código abierto; arreglar un error ortográfico es fácil y no requiere de mucha experiencia en GitHub o Git.
 
## 📝 Instrucciones: 

1. Encuentra un error ortográfico en las lecciones, proyectos o ejercicios de 4Geeks y crea un pull request con la solución.

> 👉 **IMPORTANTE**: busca otro proyecto para corregir, este proyecto ya se ha corregido lo suficiente 😂

## 🔷 Cómo corregir un error ortográfico en una lección de 4Geeks: 

![editar en Github](https://github.com/breatheco-de/the-misspell-chalenge/blob/master/assets/github-logo2.png?raw=true) 

1. **Elige una lección o proyecto** de [4Geeks Academy en GitHub](https://github.com/4GeeksAcademy).
   
2. Haz clic en el ícono del lápiz que dice "Editar en Github" en la parte superior derecha de la página, y te llevará directamente al archivo de github.

3. Si no tienes permisos para editar directamente, GitHub te ofrecerá crear un **fork del repositorio** (una copia del proyecto en tu cuenta). Haz clic en **“Fork this repository”** y continua.

4. Haz el cambio en tu proyecto.

5. Una vez hecho el cambio, haz clic en el botón **“Commit changes” → “Create pull request”** que está en la esquina superior derecha.

6. Escribe un breve mensaje explicando qué corregiste (por ejemplo: “Corregí *progrmación* a *programación*”) y confirma el Pull Request.

¡Mucha Suerte!
