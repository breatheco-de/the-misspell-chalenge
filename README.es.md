# El desafío del *error* ortográfico  
<!-- endhide -->  

Aprender en público significa colaboración, y no tienes que ser un experto para contribuir. ¡Los errores ortográficos vienen al rescate! Son el rompehielos perfecto para las contribuciones de código abierto: arreglar uno es fácil y no requiere mucha experiencia en GitHub o Git.  

## 🔷 ¿Cómo corregir un error ortográfico en una lección de 4Geeks?  

![editar en Github](https://github.com/breatheco-de/the-misspell-chalenge/blob/master/assets/github-logo2.png?raw=true)  

1. Haz clic en el ícono del lápiz (**"Editar en Github"**) en la parte superior derecha de la lección. El archivo fuente se abrirá en modo edición.  
2. Corrige el error ortográfico que encontraste.  
3. Haz clic en **"Proponer cambio de archivo"** (pull request).  

## 📝 Instrucciones:  

1. Encuentra un error ortográfico en las lecciones, proyectos o ejercicios de 4Geeks y crea un *pull request* con la solución.  

> 👉 **IMPORTANTE**: Busca otro proyecto para corregir. ¡Este ya está *libre de errores* (o casi)! 😂
