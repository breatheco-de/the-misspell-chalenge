# The Misspell Challenge
<!-- endhide -->

Learning in public means collaboration, and you don't have to be an expert to collaborate. Misspells come to the rescue! The perfect ice-breaker for open-source contributions; fixing a misspell is easy and requires almost no GitHub or Git experience.

## 📝 Instructions:

1. Find a typo in any 4Geeks lesson, project, or exercise, and create a `pull request` with the correction.

> 👉 **IMPORTANT:** please choose a different project to correct — this one has already been fixed too many times 😂

## 🔷 How to fix a typo in a 4Geeks lesson:

![edit on Github](https://github.com/breatheco-de/the-misspell-chalenge/blob/master/assets/github-logo2.png?raw=true)

1. **Choose a lesson or project** from [4Geeks Academy on GitHub](https://github.com/4GeeksAcademy).

2. Click the pencil icon that says **“Edit on GitHub”** at the top right of the page. It will take you directly to the source file.

3. If you don’t have permission to edit directly, GitHub will prompt you to create a **fork of the repository** (a copy of the project under your account). Click **“Fork this repository”** and continue.

4. Make your correction in your forked version of the file.

5. Once you’re done, click the **“Commit changes” → “Create pull request”** button in the upper-right corner.

6. Write a short message explaining what you fixed (for example: “Fixed *progrmación* to *programación*”) and confirm your Pull Request.

Good luck and happy contributing! 🚀
