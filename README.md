# The Misspell Challenge

Ejercicio de colaboración de código abierto mediante la corrección de errores ortográficos en documentación.

## Tecnologías

Markdown y flujo de trabajo de GitHub.

## Instalación y uso

Busca un error ortográfico en un recurso de aprendizaje, propón la corrección en una rama y abre un pull request. Comprueba antes si el recurso acepta contribuciones.

Repositorio: https://github.com/jm181987/the-misspell-chalenge

## Seguridad y mantenimiento

- No subas credenciales, tokens ni archivos de entorno.
- Comprueba la configuración y los requisitos reales antes del despliegue.
- Documenta incidencias y mejoras con pasos reproducibles.
